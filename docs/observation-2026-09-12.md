   選好は学習効果と乖離するうえ、その場で聞くと社交辞令が返る

## 8. 記入済みのものをどこに置くか

**このリポジトリは公開されている。** 記入済みの用紙には
「誰がどこでつまずいたか」が残るので、そのまま置くと個人が特定される。

| もの | 置き場所 |
|---|---|
| 記入済みの用紙 | アンケート回答と**同じ非公開の場所**（運営の Google Drive） |
| 記号 ↔ GitHub ユーザー名の対応表 | 同上。リポジトリには入れない |
| 人数・割合の集計（個人が特定されないもの） | issue #30 にコメント |
| 用紙そのもの（この空欄の雛形） | このファイル |

突合の鍵が GitHub ユーザー名なのは #29 と同じ。**対応表を無くすと、
9/26 の事後アンケートともリポジトリの記録とも繋がらなくなる。**
