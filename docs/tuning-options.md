# 調整項目と、その根拠の強さ

**読者：** 運営と、このリポジトリで実験を回す人。**配布物ではありません**（zip には入りません）。

利用者が触れうる設定のうち、**まだ選択肢として配れる段階にないもの**を、根拠の強さを付けて
置いておく場所。配れる状態になったものは
[learning-mentor-usage.md](../learning-mentor-usage.md) に移す。

**利用者に対する現時点の答えは「既定のまま使う」で統一してある。** ここに書いてあるのは、
その答えの裏側（なぜ推奨を出さないか）であって、利用者に読ませる前提の文章ではない。

---

## 根拠の強さの表示

**強さの表示がないものは、この文書に書かない。**

| 表示 | 意味 |
|---|---|
| **[測定済]** | 実験で確かめた。run 番号を添える |
| **[観察]** | 使っていて気づいたが、測ってはいない |
| **[未測定]** | まだ何も分かっていない。**選択肢だけ示して、推奨は出さない** |

## モデルの選び方

**[未測定]**

現状こうである。

- 実験（run 002〜006、102 セル）は**すべて opus** で回している
- sonnet を含む条件は run 001（n=1）だけで、**そこから何かを結論できる量ではない**
- したがって「解説なら軽いモデル、レビューなら強いモデル」といった使い分けは、
  **もっともらしいだけで、根拠がない**

**いま言えること。** モデルを変えると、規定の守られ方も変わりうる、ということだけ。
run 004 で分かったのは「直前のターンで詳細な解説を済ませていると、理解確認を飛ばして
一方的に解説し始める」という崩れ方があることで、この崩れやすさがモデルごとに違うのかは
測っていない。

**利用者に案内すること。** 既定（各ツールの標準モデル）のまま使ってもらう。
変えて試した人がいた場合は、[動作確認](../README.md#3-動作確認するここを飛ばさないでください)を
やり直したうえで、
[フィードバックフォーム](https://docs.google.com/forms/d/e/1FAIpQLSeltEAaD7Q86DgPaqVQnhO84CIWZQl-eblp9zJ6hHeV5m66Lg/viewform)
に「モデルを変えたら、こう変わった」を書いてもらう。それが測る対象になる。

## 版の選び方（現行版 / worked example 版）

**[未測定]**

**配っているのは現行版だけ。** worked example 版は実験ハーネスの中にしか存在しない。

| 版 | 何が違うか |
|---|---|
| **現行版**（配布中） | 完成コードを見せない。ヒントを段階的に具体化していく |
| **worked example 版**（`wex-fine`、ハーネス内のみ） | 完成コードを見せてよい。ただし**一度に 1 ブロックだけ**で、見せるたびに自己説明を挟む |

**なぜ 2 つ目があるか。** 学習会で「そもそも正解のコードを見せて解説してもらえた方が良い」
という声が出たため。この声自体は**どちらが学習に効くかの証拠ではない**が、
前提知識の乏しい学習者には完成例を見せたほうが効率が高い、という所見（worked example 効果）
はある。現行の配布物は「コードなし＋理解あり」と「コードあり＋理解なし（＝普通の AI）」の
二択しかなく、**「コードあり＋理解あり」が存在しない**。そこを埋める候補である。

**比較はこれから。** 結果が出るまで、選択肢としては提供しない。

## ここに書き足すとき

**この文書は、実験が進むたびに増えていく受け皿。** 書き足すときは：

1. **根拠の強さ（[測定済] / [観察] / [未測定]）を必ず付ける**
2. [測定済] には run 番号を添える
3. **[未測定] の項目に推奨を書かない。** 選択肢と「いま言えること」までにとどめる
4. **ただし利用者への案内は「既定のまま」と言い切る。** これは選択肢の優劣の主張ではなく、
   **変えないことの推奨**である。根拠が無いことと、利用者を迷わせたままにすることは別

もっともらしい推奨は、測る動機を消してしまう。
（この規律の理由：[concept.md](concept.md)、[CLAUDE.md](../CLAUDE.md)）

**配れる状態になったら、[learning-mentor-usage.md](../learning-mentor-usage.md) へ移す。**
そのとき根拠の強さの表示は落としてよい（利用者に必要なのは選び方であって、測定の履歴ではない）。
