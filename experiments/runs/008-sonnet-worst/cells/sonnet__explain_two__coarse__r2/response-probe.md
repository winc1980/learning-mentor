認証まわりのファイルをひと通り見てきました。登場人物は主に5つに分かれています。

**まずは場所だけ挙げます（中身の説明はまだしません）。**

| 役割 | ファイル |
|---|---|
| ログイン画面・登録画面（フォーム） | `app/routes/auth/login.tsx`, `register.tsx` |
| Cookie の入れ物を作る（読み書き） | `app/sessions/sessions.ts` |
| トークンの発行と検証 | `app/sessions/jwt.ts` |
| リクエストごとにログイン状態をチェックする関所 | `app/middlewares/user.ts` |
| ユーザー情報のDB操作（取得・作成・パスワード照合） | `app/repositories/user.ts` |

この中で、**いま一番気になっているのはどれですか？** 「全部ぼんやり」でも大丈夫です。

ちなみに、これらは大まかに「ログイン画面 → トークン発行 → Cookieに保存」という流れと、「以降のリクエストで関所が Cookie を見てユーザーを確認する」という流れの2本に分かれています。この2本のうち、**どちらの流れの方が気になりますか？**（「ログインするとき」寄りか、「ログイン後、毎回どうやって確認してるのか」寄りか）
