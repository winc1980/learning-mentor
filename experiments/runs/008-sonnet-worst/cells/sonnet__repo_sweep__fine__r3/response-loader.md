実は今のセッション、作業ディレクトリが `experiments/fixture` に固定されていて、そこより上の階層（リポジトリのルートや `docs/`, `experiments/` 本体など）を直接読む権限がありませんでした。なので実ファイルを見ての確認はできなかったのですが、代わりに渡されている `CLAUDE.md`（リポジトリの規約文書）に構成がかなり具体的に書かれているので、それをもとに地図を作ります。**中身の説明はまだしません**、まず位置関係だけです。

## このリポジトリが何をするものか

AI に「学習と解説だけ」をさせる役割定義（プロンプト文章）を作り、配布し、更新し、そして**その規定が本当に守られているかを実験で測る**仕組み一式です。プロダクトはコード（プログラム）ではなく**文章**、という点がこのリポジトリの構成の癖に効いています。

## 場所の地図

| 場所 | 何があるか |
|---|---|
| `learning-mentor-prompt.md` | メンターの役割定義の**本文の正本**（唯一の書き込み元） |
| `learning-mentor-setup.md` | 配置用。本文のコピーが埋め込まれている |
| `learning-mentor-usage.md` | 配れる状態になった利用者向けドキュメント |
| `.claude/agents/learn.md` | `claude --agent learn` 用の本文コピー |
| `VERSION` | バージョン番号（リリースタグと一致させる対象） |
| `check-sync.ts` | 本文コピー3箇所のズレを検知するスクリプト |
| `mentor-update.ts` | 配置先・更新状態を確認するスクリプト |
| `docs/` | 企画意図など、腐らない内部文書（配布物には入らない） |
| `experiments/` | 実験ハーネス一式（規定が守られるかを測る仕組み） |
| `experiments/fixture/` | 被験体（AI）が実際に読むリポジトリの実体（今あなたがいる場所） |
| `experiments/runs/` | 過去の実験の生データ（消さない・書き換えない） |
| `experiments/rubric.md` | 採点基準（版によって意味が変わる） |
| `experiments/DECISIONS.md` | 「測らないと決めたこと」の記録 |
| `.github/` | CI・issue テンプレート |

一番の特徴は、**同じ文章が3箇所にコピーされていて、それを人力で同期させている**ことです。ここが崩れるとメンターが「別物」になってしまう、という点がこのリポジトリ最大の注意点になっています。
