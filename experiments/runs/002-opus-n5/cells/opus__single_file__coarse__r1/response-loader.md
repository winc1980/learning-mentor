## このファイルは何のためにあるか

**「時刻を持たない日付」だけを表す型**を、自前で用意しているファイルです。

JavaScript 標準の `Date` は、日付だけでなく **時刻とタイムゾーンも必ず持ちます**。「2026年9月7日」と言いたいだけなのに `Date` を使うと、「9月7日の00:00:00 (JST)」のような余計な情報がくっついてきて、タイムゾーンがずれた瞬間に日付が1日前後する、という事故が起きます。

このプロジェクトは「ライブの開催日」「バンドの空き日」みたいなものを扱っているようなので（`live-day.ts` などから参照されています）、時刻は要らない。だから `year` / `month` / `day` の3つだけを持つ箱を自分で定義している、というのがこのファイルの動機です。

## 中身は大きく3ブロック

1. **`PlainDateLike` 型と `PlainDate` クラス本体**（3〜12行、35〜49行）
   年月日3つを保持するだけ。ただしコンストラクタで `month` が1〜12か、`day` が1〜31かを検証して、外れていたら例外を投げます。＝**不正な値を持った `PlainDate` は最初から作れない**、という作りです。

2. **`static serde`**（14〜33行）
   `"2026/9/7"` のような文字列 ⇄ `PlainDate` の相互変換。`serialize` がオブジェクト→文字列、`deserialize` が文字列→オブジェクト。フォームの値やURLパラメータなど、文字列としてしか運べない場所を通すときに使うためのものです。

3. **`static now()`**（51〜58行）
   今日の日付を `PlainDate` として作る。`Date` の `getMonth()` が0始まり（1月=0）なので、`+1` して1始まりに直しているのがポイントです。
