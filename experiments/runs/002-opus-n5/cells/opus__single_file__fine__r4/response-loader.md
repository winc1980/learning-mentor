`app/lib/plain-date.ts` を読みました。まず全体像から。

## 一言でいうと

**「年・月・日」だけを持つ日付を表す、自作の型（クラス）** です。時刻もタイムゾーンも持ちません。

## なぜこんなものを作るのか

JavaScript の組み込みの `Date` は、日付だけを扱いたいときに困ることがあります。`Date` は必ず「時刻」と「タイムゾーン」を抱えているからです。たとえば「9月7日」を表したいだけなのに、内部的には「9月7日の00:00:00 JST」のような値になり、UTC に変換した瞬間に9月6日になったりします。

なので「誕生日」「締切日」のように *日付だけ* が意味を持つデータでは、時刻を持たない専用の型を用意する、というのがよくある設計です。名前の `Plain`（=素の、余計なものが付いていない）はそこから来ています。

## ファイルの中身は3ブロック

| 場所 | 役割 |
|---|---|
| `PlainDateLike` 型 + `constructor`（35〜49行） | 年月日を受け取ってオブジェクトを作る。このとき月が1〜12か、日が1〜31かをチェックして、外れていたらエラーを投げる |
| `static serde`（14〜33行） | `PlainDate` ⇄ `"2026/9/7"` という**文字列との相互変換**。保存したり通信で送ったりするときに使う |
| `static now()`（51〜58行） | 「今日」の `PlainDate` を作るショートカット |

`serde` という名前は **ser**ialize（オブジェクト→文字列）と **de**serialize（文字列→オブジェクト）の合成です。同じディレクトリの `serde.ts` に、この2つをペアで持つという約束事（インターフェース）が定義されていて、`PlainDate` はそれに従っています。
