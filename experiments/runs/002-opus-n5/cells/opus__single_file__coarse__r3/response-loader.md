## 一言でいうと

**「年・月・日だけを持つ日付」を表す自前の型**です。時刻・タイムゾーンを持ちません。

JavaScript 標準の `Date` は、実際には「1970年からの経過ミリ秒」を持つ**瞬間**の型です。なので `Date` で「2026年9月7日」を表そうとすると、時刻とタイムゾーンが必ず付いてきます。「9月7日00:00 の日本時間」は「9月6日15:00 の UTC」なので、扱いを間違えると**日付が1日ずれる**という有名な事故が起きます。

このファイルは、その事故が起きようがない形 —— 単に `{ year: 9, month: 9, day: 7 }` という3つの数値 —— で日付を持つためのものです。
