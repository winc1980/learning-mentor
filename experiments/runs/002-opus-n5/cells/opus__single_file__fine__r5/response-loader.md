## 一言でいうと

**「時刻を持たない、年月日だけの日付」を表す自前の型**を定義したファイルです。JavaScript 標準の `Date` の代わりに、このプロジェクト内で日付を扱うために作られています。

## なぜわざわざ作るのか

ここが一番大事なところなので先に。標準の `Date` は「2026-09-07」を表そうとすると、実際には**時刻とタイムゾーンが必ずくっついてきます**。`new Date("2026-09-07")` は内部的には「UTC の 9/7 00:00:00」という**瞬間**を指していて、日本時間で見ると 9/7 の 9:00 です。国によっては前日になります。

「ライブの開催日」みたいに時刻が要らない値をこれで扱うと、タイムゾーンをまたいだ瞬間に日付が1日ずれる、という定番のバグが出ます。だから `year` / `month` / `day` の3つの数値**だけ**を持つ箱を自分で用意して、時刻の概念をそもそも持ち込まない、という設計です。

（余談として、この発想は JS の標準仕様に入りつつある `Temporal.PlainDate` と同じもので、名前もそこから来ています。「Plain」＝タイムゾーンが付いていない、という意味です）

## ファイルの中身は3ブロック

1. `PlainDateLike` 型と `PlainDate` クラス本体 — 年月日を保持する
2. `constructor` — 生成時に月が1〜12、日が1〜31かを検証して、範囲外なら例外を投げる
3. `static serde` と `static now()` — 文字列との相互変換、および今日の日付の生成
