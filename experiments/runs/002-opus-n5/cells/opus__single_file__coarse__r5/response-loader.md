## 一言で

**「2026年9月7日」のような “日付だけ” を表す自前のデータ型**を定義しているファイルです。時刻もタイムゾーンも持ちません。

## なぜこんなものを自作するのか

JavaScript 標準の `Date` は、必ず「時刻」と「タイムゾーン」を一緒に持っています。だから「誕生日」や「締切日」のような、時刻に意味がない値を `Date` で扱うと、

- `2026-09-07T00:00:00` を別のタイムゾーンで表示したら 9/6 になる
- 「同じ日か？」を比較するのに、いちいち時分秒を切り落とす必要がある

といった事故が起きます。それを避けるため、**year / month / day の3つだけを持つ箱**を用意した、というのがこのファイルの動機です。（Temporal API の `PlainDate` という提案から名前を取っています）

## 中身は3つの部品でできています

1. **`PlainDateLike` 型と `PlainDate` クラス（3〜12行, 35〜49行）** — 年月日を持つ箱の定義。コンストラクタで「月は1〜12」「日は1〜31」を検査していて、範囲外なら例外を投げます。つまり**壊れた PlainDate は存在できない**という作りです
2. **`static serde`（14〜33行）** — `"2026/9/7"` のような文字列との相互変換。オブジェクトを保存・送信できる形（ここでは文字列）に変換することを**シリアライズ**、その逆を**デシリアライズ**と呼びます
3. **`static now()`（51〜58行）** — 標準の `Date` から今日の日付を取り出して `PlainDate` を作るショートカット
