認証は、このアプリの中で **一番ファイルが分散している部分** です。「分からない」のは自然だと思います。

**まず登場人物の場所だけ挙げます。中身の説明はまだしません。**

---

## 認証に関わる7つの場所

| 役割 | ファイル |
|---|---|
| ① Cookie の入れ物を作る | `app/sessions/sessions.ts` |
| ② トークンの発行と検証 | `app/sessions/jwt.ts` |
| ③ 門番（未ログインなら追い返す） | `app/middlewares/user.ts` |
| ④ 門番をルートに取り付ける | `app/routes/app/app-middleware.tsx` |
| ⑤ どの URL が門の内側かの線引き | `app/routes.ts` |
| ⑥ 入口・出口の画面と処理 | `app/routes/auth/login.tsx`, `register.tsx`, `logout.tsx` |
| ⑦ パスワードの取り扱い | `app/lib/hash.ts` |

補助として、ユーザーの読み書きが `app/repositories/user.ts`、認証系のエラー型が `app/domain/data/errors.ts` にあります。

**大まかな向き**（これも中身ではなく位置関係だけ）：

```
登録/ログイン画面 ⑥ ──> ② でトークン発行 ──> ① で Cookie に載せる
                                                    │
以降のリクエスト ──> ⑤ で門の内側と判定 ──> ④ ──> ③ が ① から取り出し ② で検証
```
