## 大きく2つに分かれます

このリポジトリは **「教材そのもの（アプリ本体）」** と **「学習会の運営資料」** が同居しています。

| | 場所 |
|---|---|
| アプリ本体のコード | `app/` |
| DBマイグレーション | `drizzle/` |
| 学習会の進め方・環境構築 | `README.md` / `docs/` |
| 課題の元ネタ（Issue 7本） | `issues/` |
| セットアップ用スクリプト | `scripts/` |

`README.md` を見る限り、Issue 1〜7 を解いていく形式の教材リポジトリですね。

## `app/` の中の階層

ここが本体です。役割ごとに分かれています。

| 役割 | 場所 |
|---|---|
| **どのURLがどのファイルか**の対応表 | `app/routes.ts` |
| 各ページの実体 | `app/routes/` 配下 |
| ページ表示前に挟まる処理 | `app/middlewares/` と `*-middleware.tsx` |
| DBの接続とテーブル定義 | `app/db/index.ts` / `app/db/schema.ts` |
| DBの読み書き | `app/repositories/` （band / live / user） |
| ドメインの型・ルール | `app/domain/entities/` |
| ログイン状態の保持 | `app/sessions/` （jwt / sessions） |
| 汎用の道具 | `app/lib/` （result, hash, plain-date など） |
| 見た目の部品 | `app/components/ui/`（shadcn 由来）と `app/components/common/`（自作） |

`app/routes/` の中はさらに URL の形と対応していて、`auth/`（ログイン系）、`app/`（ログイン後）、`app/live/`（ライブ単位）、`app/live/band/`（バンド単位）と入れ子になっています。
