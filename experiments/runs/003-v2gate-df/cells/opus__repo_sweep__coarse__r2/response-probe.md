- `sessions.ts` と `jwt.ts` が **別ファイルに分かれている**こと、そして秘密鍵が **2つある**ことが、この設計の一番の特徴です。ここが「なぜ2つ？」と引っかかりやすい場所です。
- `routes.ts` の中で、`auth/` 配下と `app/` 配下は**別の階層**に置かれています。守られている範囲の境界線がここに書いてあります。
