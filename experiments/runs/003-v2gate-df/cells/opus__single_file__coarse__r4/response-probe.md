一通り読みました。認証の登場人物は、大きく **5つの役割** に分かれています。**まずは場所だけ挙げます。中身の説明はまだしません。**

| 役割 | ファイル |
|---|---|
| ① Cookie の入れ物を作る・読む・書き戻す | `app/sessions/sessions.ts` |
| ② トークンの発行と検証（JWT） | `app/sessions/jwt.ts` |
| ③ 「ログインしてないなら弾く」門番 | `app/middlewares/user.ts` |
| ④ 入口の画面と処理（登録・ログイン・ログアウト） | `app/routes/auth/{register,login,logout}.tsx` |
| ⑤ 門番をどのルートに掛けるかの配線 | `app/routes.ts` / `app/routes/app/app-middleware.tsx` |

周辺に、パスワードを扱う `app/lib/hash.ts`、DBからユーザーを引く `app/repositories/user.ts`、エラーの種類を定義した `app/domain/data/errors.ts` があります。

ざっくりした位置関係だけ言うと、**④で発行 → ①に格納 → ③で毎リクエスト検証**、という流れです。②は③と④の両方から呼ばれる部品です。
