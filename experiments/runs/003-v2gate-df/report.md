## 1. 何を変えたか

[experiments/variants/v2-gate.py](../../variants/v2-gate.py) が
`learning-mentor-prompt.md` に2箇所のパッチを当てて生成する。**他は1文字も変えていない**（+30行）。

**パッチ1：手順1を飛ばせなくする**（モード1の手順1に追記）

> **この手順は、材料が揃っているときほど飛ばしたくなります。** リポジトリを読めていて、
> 答えが分かっていて、きれいな全体像が書ける——そういうときこそ、確認せずに書き始めてしまいます。
> **読めていることは、相手が分かっていることの根拠になりません。**
> **材料の多さは、手順1を省く理由になりません。**

**パッチ2：広い質問への規範例**（新設の節。002 の B 条件で実際に出た言い回しを模範として採用）

> **やること：場所だけ先に示して、中身の説明はまだしない。**
> 「一通り読みました。…**まずは場所だけ挙げます（中身の説明はまだしません）。**」
> - **「中身の説明はまだしません」と声に出して言う。** 自分への歯止めになります

003 と 002 の差は spec の `agent_variant` 1行のみ。水準テキスト・ターン構成・反復数・モデルは
機械的に同一であることを検証済み。

## 4. 限界

- **完全には戻っていない。** D は 6/10、F は 8/10。素の A・B・E 条件は 10/10 だったので、
  そこには届いていない
- **人格残存度は 4 止まりで 5 が1件も出ていない。** 段5は「一番最初に前提の理解確認がある」。
  v2-gate は「場所だけ挙げてから確認」という形なので、構造上4になる。
  これが問題かどうかは判断が要る——**規範例そのものが段4の形をしている**
- **D のほうが改善が小さい（6/10 対 8/10）。** D は 002 でも C と並ぶ異常条件だった。
  未解明の C の問題と根が同じ可能性がある
- n=5・opus のみ・coarse のみ。sonnet と fine 条件では未検証

## 5. 推奨

**マスター（`learning-mentor-prompt.md`）への取り込みを推奨する。**

根拠：
- 0/20 → 14/20 で、床からの改善が明確
- 固有識別子の混入という明確な規約違反が 10/10 → 0/10 で消えた
- 崩れていなかった条件を壊していないかは未検証だが、パッチは
  「手順1を飛ばすな」「広い質問では場所だけ示せ」という**既存の規定の補強**であり、
  新しい規則の追加ではない

取り込み手順：

```bash
python experiments/variants/v2-gate.py --diff   # 差分を確認
# learning-mentor-prompt.md に手で当てる（マスターが唯一のソース）
python check-sync.py                            # 3ターゲットの貼り直し漏れを検出
```

**取り込み前にやるべき確認：** 崩れていなかった条件（A・B・C・E）を v2-gate で回し、
**改善が退行を伴っていないか**を見る。特に fine 条件で余計な前置きが増えていないか。
20セル / 40ターンで済む。
