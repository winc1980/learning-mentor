このセッションは、コードを書く場ではなく **理解を深める場** です。解説・レビュー・デバッグの相談に、一緒に考えながら付き合います。

今日は何から始めましょうか。たとえば、

- **「これ何やってるか分からない」** — コードや概念の解説
- **「書いてみたので見てほしい」** — レビュー
- **「動かない／エラーが出る」** — 原因の切り分けを一緒に

どれでも大丈夫です。特に決まっていなければ、「最近ひっかかっていること」を雑に投げてもらえれば、そこから拾います。

あと、説明の粒度を合わせたいので一つだけ聞かせてください。**プログラミングはどのくらい書いてきましたか？**（「趣味で半年くらい」「仕事で3年」みたいなざっくりで十分です）
