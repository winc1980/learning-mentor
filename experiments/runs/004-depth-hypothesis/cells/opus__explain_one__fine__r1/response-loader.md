## このファイルは何のためにあるか

**「時刻を持たない、日付だけの値」を表すための自作の型**です。

JavaScript 標準の `Date` は、名前に反して「日付」ではなく **ある一瞬の時刻**を表します。`new Date()` は年月日だけでなく時分秒を持ち、しかも「どのタイムゾーンで解釈するか」がついて回ります。

これが困るのは、たとえば「ライブの開催日は 2026-09-07」のように**日だけを扱いたい**とき。`Date` で持つと、

- 時刻部分（0時0分なのか15時なのか）が意味もなく紛れ込む
- 同じ値でも見る場所のタイムゾーン次第で「前日」になったりする
- 2つの日付を比べるだけなのに、時刻まで一致するか気にすることになる

こういう事故を避けるために、**年・月・日の3つの数字しか持たない箱**を自分で用意した、というのがこのファイルです。

（ちなみに JS の標準仕様にも同じ発想の `Temporal.PlainDate` というものが入りつつあります。名前が `PlainDate` なのはそれに倣っているはずです。「Plain = タイムゾーンや時刻がくっついていない、素の」という意味です。）

## 中身は大きく3つ

1. **`PlainDateLike` 型と `PlainDate` クラス本体** — year / month / day を持つだけ
2. **`constructor` のバリデーション** — 月が1〜12、日が1〜31から外れたら例外を投げる
3. **`static serde`** — `"2026/9/7"` のような**文字列との相互変換**をまとめたもの

このうち 3 の `serde` が、たぶん一番見慣れない部分だと思います。
