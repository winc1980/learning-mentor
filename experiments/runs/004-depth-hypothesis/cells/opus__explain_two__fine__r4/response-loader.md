## plain-date.ts ── 「時刻のない日付」を表すための型

JavaScript の `Date` は、日付だけを扱いたいときでも必ず**時刻とタイムゾーンがくっついてきます**。「2026年9月7日」と言いたいだけなのに、実体は「協定世界時の何時何分何秒」です。

そのせいで起きるのが、たとえばこういうこと：

- 誕生日を保存したら、環境によって1日ずれる
- 「同じ日か？」を比べたいのに、時刻が違うので一致しない

このファイルは、その面倒を避けるために **year / month / day の3つの数字だけを持つ自前の型**を用意しています。時刻もタイムゾーンも最初から存在しないので、ずれようがない、という発想です。

ついでに、その型を**文字列に変換したり、文字列から復元したり**する仕組み（`serde`）と、生成時に「月が13」みたいな変な値を弾くチェックも入っています。

## result.ts ── 「失敗するかもしれない処理」の結果を表す型

こちらは日付とは無関係で、**エラーの扱い方**の話です。

普通の JavaScript だと、失敗は `throw` で伝えます。でも `throw` には弱点があって、**関数の型を見ても「これは失敗しうる」と分からない**んです。だから呼ぶ側が try/catch を書き忘れても、TypeScript は何も言ってくれません。

そこでこのファイルは、**失敗を「投げる」のではなく「返す」**方式にしています。成功なら `Success`（中に値が入っている）、失敗なら `Fail`（中にエラーが入っている）を返す。戻り値の型が `Result<T, E>` になるので、**呼ぶ側は成功か失敗かを確認しないと中身を取り出せません**。型で強制される、というのが狙いです。

Rust や Go のエラーハンドリングを TypeScript に持ち込んだ形、と言うと通じるかもしれません。
