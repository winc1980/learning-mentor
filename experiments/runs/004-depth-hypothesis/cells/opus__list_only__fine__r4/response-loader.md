`app/lib` には8ファイルあります。

| ファイル | 名前から推測される役割 |
|---|---|
| `error.ts` | エラー型・エラー処理 |
| `hash.ts` | ハッシュ関連 |
| `plain-date.ts` | 日付（時刻なし）の扱い |
| `plain-datetime-utils.ts` | 日時のユーティリティ |
| `plain-time.ts` | 時刻の扱い |
| `result.ts` | Result型（成功/失敗を値で返すパターン）と思われる |
| `serde.ts` | シリアライズ/デシリアライズ |
| `utils.ts` | 汎用ヘルパー |

サブディレクトリはなく、すべて直下のフラットな構成です。

`plain-` で始まる3つと `result.ts` あたりは、この構成だと何らかの設計方針が背後にありそうです（Temporal API 系か、独自の値オブジェクトか）。中身を読んで解説したいものがあれば言ってください。
