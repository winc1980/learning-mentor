一通り読みました。このアプリの認証は、だいたい6つの登場人物に分かれています。

**まずは場所だけ挙げます。中身の説明はまだしません。**

| 役割 | ファイル |
|---|---|
| Cookie の入れ物を作る | `app/sessions/sessions.ts` |
| トークンの発行と検証 | `app/sessions/jwt.ts` |
| パスワードのハッシュ化・照合 | `app/lib/hash.ts` |
| ログイン処理（フォーム受け取り） | `app/routes/auth/login.tsx` の `action` |
| 新規登録・ログアウト | `app/routes/auth/register.tsx` / `logout.tsx` |
| 「ログイン済みか」を毎リクエスト判定する門番 | `app/middlewares/user.ts` |

そして、この門番がどこに効いているかは `app/routes.ts` で決まっています（`/app` 以下にだけ挟まっています）。
